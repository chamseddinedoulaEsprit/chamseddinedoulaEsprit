### 🍽️ Savour — Multimodal Recipe Recommendation with Agentic AI

**Tech:** Python · Qwen3 · QLoRA · RAG · BGE-M3 · Qdrant · Ollama · Gemma 3 · n8n

An intelligent recipe recommendation assistant combining deep learning, multimodal AI, and multi-agent orchestration.

- Fine-tuned **Qwen3-0.6B using QLoRA** for structured intent extraction.
- Implemented semantic retrieval over approximately **221,741 recipes** using BGE-M3 and Qdrant.
- Designed an AI Supervisor coordinating retrieval, ranking, generation assistance, and validation.
- Integrated local LLMs through Ollama and automated workflows using n8n.
- Achieved **98.25% accuracy** on a held-out synthetic intent extraction test set, compared with **35.09%** for the base model.
